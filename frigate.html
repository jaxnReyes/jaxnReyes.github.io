Containerized AI & Computer Vision Stack

A containerized AI-driven security and object detection pipeline utilizing Frigate NVR, Double Take, and InsightFace with hardware acceleration on dedicated edge compute boards.

Frigate NVR Docker Compose NVIDIA Jetson Xavier TensorRT Acceleration Double-Take & InsightFace MQTT Broker

Surveillance Topology & Inference Pipeline

Low-latency video stream decoding and real-time object/facial recognition pipeline integrated across local edge hardware.

End-to-End Inference & Event Execution Lifecycle

  1. RTSP Stream Ingestion: Frigate container pulls live camera feeds via RTSP, where hardware-accelerated decoding processes video frames and performs initial object detection.
  2. MQTT Event Trigger: Upon detecting an object or target class, Frigate fires an initial MQTT Event Trigger payload to Double-Take (Unified Face Processor).
  3. HTTP Snapshot Request: Double-Take queries Frigate via an HTTP Snapshot Request to retrieve high-resolution bounding box image crops.
  4. HTTP POST Image (Face Crop): Double-Take forwards the extracted facial snapshot via an HTTP POST request to the custom FastAPI / DeepStack-spec container running on a dedicated Jetson Xavier node.
  5. Model Inference & JSON Response: The InsightFace Inference Engine running on NVIDIA hardware executes facial vector comparison and returns a JSON Response containing verified names and confidence percentages.
  6. MQTT Match Result & Automation: Double-Take processes the match data and dispatches an MQTT Match Result payload to Home Assistant to trigger real-time automation routines, security alerts, and event dashboards.

Multi-Host Infrastructure & Architecture Highlights

Proxmox VE Microservice Isolation

Runs unprivileged Linux Containers (LXC) to isolate Frigate NVR, Double-Take, and Home Assistant microservices. This preserves hypervisor resources while maintaining low-latency network I/O and event routing across virtual interfaces.

Hardware-Accelerated Edge Offloading

Offloads heavy CUDA/TensorRT matrix calculations and facial recognition workloads to a dedicated NVIDIA Jetson Xavier host running Docker Compose.

Custom API Interoperability

Implements a custom FastAPI / DeepStack-spec wrapper around InsightFace in Python, enabling seamless API integration with Double-Take while maintaining real-time inference speed on edge hardware.
