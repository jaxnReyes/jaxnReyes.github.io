Gym Membership Attrition Prediction Model

Predicting member churn risk through supervised machine learning, XGBoost classification, and SMOTE data balancing.

Python 3.12 XGBoost Scikit-learn SMOTE Pandas & NumPy Git / GitHub
Problem Statement & Professional Context

Member attrition represents the primary driver of unexpected revenue loss for gyms and health clubs. Traditional management frameworks rely heavily on reactive feedback mechanisms (such as Listen360), which capture only a fraction of dissatisfied members before cancellation notices are submitted.

Professional Context: Inspired by my hands-on expeerience servicing regional fitness facilities, this project bridges advanced machine learning coursework with real-world membership lifecycle management, shifting management from reactive cancellation handling to proactive, data-driven retention strategies.

Data Preprocessing & Feature Engineering

The automated data pipeline ingests raw operational data, preparing features for robust predictive classification:

  • Data Ingestion & Sanitization: The dataset is stripped of non-predictive PII (names, phone numbers).
  • Missing Value Imputation: Continuous numerical features are cleaned and imputed using median values to prevent pipeline exceptions.
  • Categorical Encoding & Scaling: Categorical features are transformed using one-hot encoding, and numerical attributes are standardized.
  • Class Balancing via SMOTE: Synthetic Minority Over-sampling Technique (SMOTE) is applied on training data to mitigate severe class imbalance between active and churned members.
Model Training & Evaluation Metrics

Implemented an XGBoost (eXtreme Gradient Boosting) decision tree ensemble model optimized via GridSearchCV hyperparameters (n_estimators, max_depth, min_child_weight) to evaluate non-linear feature relationships.

88.0% Evaluated Recall Score
82.0% Evaluated F1 Score
≥ 0.85 Recall Target Met
Actionable Insights & Business Impact

The trained model generates high-risk member reports for General Managers and Membership Leads.

  • Proactive Retention: Empowers staff to initiate targeted outreach and personalized engagement before account cancellation.
  • Secure Local Deployment: Runs locally on an isolated workstation environment, ensuring sensitive member data never crosses public networks.
